Open format · draft 0.1

Engineering models that move and calculate, in one file.

A .slfy file carries a 3D machine and its engineering: parts placed by how they fit, motion, sizes as sliders, and the calculations and charts that go with it. Open one, turn it, run it, change a size and watch the working follow.

Open the viewer Read the spec GitHub

What a file holds

Parts from real shapes

Gears, pulleys, sprockets, springs, bolts, lathe profiles and extrusions, with boolean cuts. Any size can be a formula of the model's values.

Placed by relation

On a shaft, meshing with a gear, driven by a crank, through a Hooke's joint: the file says how parts fit, and the positions follow.

Motion

Name the driver; everything it drives turns, slides and swings with it at the right ratio.

Live calculations

Equations worked in order from the model's own sizes, with limits flagged, so moving a slider re-works everything.

Charts and forces

Bending moment diagrams and curves sampled from formulas; loads, moments and dimensions attached to parts.

Worked questions

A problem's givens as sliders and its solution as numbered steps with answers, so a textbook question becomes a model.

Use it

Open a file

Drop any .slfy on the viewer, or link to one: https://slfy.solidify.studio/viewer/?file=https://…/model.slfy (the site holding the file must allow it to be fetched; GitHub's raw files do).

Put a live model on your page

<iframe src="https://slfy.solidify.studio/viewer/?embed=1&file=https://…/model.slfy"
        width="100%" height="460" style="border:0;border-radius:16px" loading="lazy"></iframe>

Check a file

Validate against the JSON Schema with any JSON Schema 2020-12 validator; the specification says how files are drawn and worked out.

Make files

Write them by hand (start from the examples), generate them from your own tools, or build one in Solidify and download it.
